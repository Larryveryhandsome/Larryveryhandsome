## 🧠 做事方法（正經版）

1. **先自己用，再拿出來給別人用。** 開源的東西都在真的店裡跑過。
2. **形式可以不正經，實質一律正經。** 碰到錢、法規、員工權益，一定照規矩來。
3. **AI 做苦工，人做判斷。** 要對外發出去的，一律人看過才發。
